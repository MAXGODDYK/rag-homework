## Висновок

Baseline semantic retrieval добре знаходить конкретні поради про режим дня, пріоритети, підготовку до іспитів, сон і відпочинок. Мультимовна модель коректно зіставляє українські запити з українськими chunks навіть без точного збігу всіх слів. Найсильніший результат отримано для запиту про режим дня студента (`0.8649`).

Слабші результати помітні для вузьких формулювань про перерви та контроль виконання. FAISS завжди повертає top-k найближчих chunks, навіть коли частина з них відповідає лише загальній темі. У наступній версії retrieval можна покращити за допомогою score threshold, metadata filtering, hybrid search або reranking.
